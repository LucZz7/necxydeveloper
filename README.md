# NECXY DEVELOPER — Portfolio

Professional animated portfolio website with a **Glassmorphism Red / Black / White** theme.

## Tech
- Pure **HTML / CSS / JavaScript** (no frameworks, no build step)
- Fully responsive, animated, and self-hostable

## Structure
```
necxy-portfolio/
├── index.html          # Main page
├── favicon.svg         # Circular favicon
├── README.md
├── css/
│   └── style.css       # All styles & animations
├── js/
│   └── main.js         # Interactions (cursor, reveal, counters, tilt)
└── assets/
    └── profile.png     # Profile image
```

## Run
Just open `index.html` in a browser — nothing else needed.

## Deploy
Works on any static host: **GitHub Pages, Netlify, Vercel, Cloudflare Pages**.

## Sections
- Hero (animated avatar, rotating ring, floating contact chips)
- About (bio + animated skill bars)
- Contact (Telegram, Channel, WhatsApp, Instagram)

## Customize
- **Text & links**: edit `index.html`
- **Colors**: edit CSS variables in `css/style.css` (`:root`)
- **Profile image**: replace `assets/profile.png`
